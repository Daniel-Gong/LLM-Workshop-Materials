# LLM-Workshop-Materials

This is the repository for a workshop series at Yale on "Building LLMs from Scratch", using mainly materials from this [textbook](https://www.manning.com/books/build-a-large-language-model-from-scratch) and code from this [repository](https://github.com/rasbt/LLMs-from-scratch). The digital version of the textbook is available from [Yale Library](https://search.library.yale.edu/catalog/991010655998708651?block=Books).

This is a biweekly workshop that takes place every other Tuesday at 7:00pm, and we will provide dinner 30 minutes before the workshop. The location is Room 1116, 100 College St. Below is the tentative schedule:

- Feb 3: Workshop Overview and Environment Setup
- Feb 17: Working with Text Data
- Mar 3: Coding Attention Mechanisms
- Mar 24: Implementing a GPT Model from Scratch
- Apr 7: Pretraining on Unlabeled Data
- Apr 21: Fine-tuning for Text Classification
- May 5: Fine-tuning to Follow Instructions
